## 📁 Project Structure

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### Files

**`index.html`**
Contains the semantic structure and content of the portfolio.

**`style.css`**
Contains the complete responsive design system, layouts, animations, themes, and component styling.

**`script.js`**
Handles:

* Theme switching
* Mobile navigation
* Scroll behavior
* Section detection
* Scroll-reveal animations
* Accessibility-related interactions

## 📱 Responsive Design

The portfolio is designed to work across:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

The navigation, project layouts, typography, cards, and spacing adapt automatically to smaller screens.
